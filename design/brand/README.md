# Brand assets

| File | Use |
|---|---|
| `logo/trik-mark.svg` | The three-tick mark on light backgrounds |
| `logo/trik-mark-on-ink.svg` | The mark on Ink (dark) backgrounds |
| `logo/trik-lockup-paper.svg` | Mark + wordmark on light |
| `logo/trik-lockup-ink.svg` | Mark + wordmark on dark |
| `logo/trik-app-icon.svg` | App icon and favicon source |

The lockups use live text in Space Grotesk. Before printing or sending to third parties, convert the text to outlines in a design tool.
The full rules are in `docs/brand/Trik-Brand-and-Product-Book.pdf`.

Fonts (all free, Google Fonts): Space Grotesk, Inter, IBM Plex Sans Arabic.
