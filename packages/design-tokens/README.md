# packages/design-tokens — Trik design tokens

One source for colours, fonts, radius and spacing, used by `apps/web` (CSS variables) and `apps/mobile` (Dart theme).

| File | Use |
|---|---|
| `tokens.json` | Source of truth |
| `tokens.css` | CSS variables for the web app (`var(--trik-color-indigo)`) |

Brand rules (from the brand book):
- **Lime** appears only where an order is confirmed: the third tick and the Trik'd label. Always with Ink text.
- White text on Indigo passes contrast at 6.5:1. Never put lime on light backgrounds.
