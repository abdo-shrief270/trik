# ADR 0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-25

## Context

We need a lightweight record of decisions that are expensive to reverse.

## Decision

We write an ADR for every such decision, numbered, in `docs/architecture/adr`. ADRs are never edited after acceptance; a new ADR supersedes an old one.

## Consequences

Anyone can see why the system is the way it is.
