# ADR 0008: Shared risk network: opt-in, outcomes only, after legal clearance

- **Status:** Accepted
- **Date:** 2026-11-25

## Context

Refusal history across sellers would improve risk scores, but sharing data across sellers raises Meta-terms and data protection issues.

## Decision

Deferred to the Scale phase. If built: opt-in only, uses store and courier outcomes only (never WhatsApp data), identifiers stored as keyed HMAC, and only after written legal clearance.

## Consequences

No cross-seller data at launch. Risk scores start from each seller's own history.
