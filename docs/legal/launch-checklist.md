# Launch checklist (legal and platform)

- [ ] Company registered, tax card and commercial register
- [ ] Trademark search and filing: "Trik" and the tick mark, classes 9 and 42 (Egypt, Saudi Arabia; Madrid later)
- [ ] Domain `trik.chat` registered; social handles reserved
- [ ] Meta Business verification
- [ ] Meta Tech Provider application approved (Embedded Signup; sellers pay Meta directly)
- [ ] Data protection: PDPL licence or permit, data protection officer, records of processing
- [ ] Cross-border data transfer permit (hosting in the EU region)
- [ ] Terms of service, privacy policy, data processing agreement, acceptable use policy
- [ ] Payment gateway agreements in the seller's own name for deposits (Trik never holds funds)
- [ ] Courier API agreements

Details: `Legal-and-Platform-Requirements.pdf`.
